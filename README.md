Stroke Detection Using Machine Learning

A machine learning and data mining project focused on predicting stroke risk using healthcare-related data.

This project was developed as part of the CIS321 Data Mining course during my Bachelor’s degree in Computer Information Systems.

📌 Project Overview

The goal of this project is to apply machine learning classification algorithms to a healthcare dataset and predict whether a patient is at risk of having a stroke.

The project demonstrates a machine learning workflow involving data preparation, analysis, model training, prediction, and performance comparison.

🤖 Machine Learning Models

Two classification algorithms were evaluated:

Model	Configuration	Kaggle Score
Decision Tree	Gini Criterion	0.58222
Gaussian Naive Bayes	GaussianNB	0.67315

Among the evaluated models, Gaussian Naive Bayes achieved the higher Kaggle score of 0.67315.

📊 Results

The project compared different machine learning classification approaches for stroke prediction.

The Decision Tree model using the Gini criterion achieved a Kaggle score of 0.58222, while Gaussian Naive Bayes achieved 0.67315.

These results demonstrate how different classification algorithms can produce different levels of predictive performance when applied to the same dataset.
